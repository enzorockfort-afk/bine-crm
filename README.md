# Bine CRM

Отдельный сайт CRM для Bine Store: сделки, клиенты, склад, задачи. Вход — по паролю.

CRM и сайт магазина подключаются к **одному** проекту Firebase. Поэтому заказы и заявки с сайта сами появляются в CRM, а остатки из CRM отключают на сайте закончившиеся размеры.

## Разделы

- **Сегодня** — выручка и прибыль за месяц, задачи и встречи, новые сделки, что заканчивается на складе.
- **Сделки** — воронки «Под заказ» и «Наличие», карточки перетаскиваются между этапами. В сделке: продажа, закупка, доставка, предоплата → прибыль и остаток; поставщик, трек-номер, срок, заметки.
- **Клиенты** — собираются из сделок по номеру телефона; размеры, бренды, метки, история.
- **Склад** — остатки по размерам и закупочная цена.
- **Задачи** — встречи, звонки, дела.
- **Данные** — резервная копия (выгрузка и загрузка JSON).

## Пароль

- **Демо-режим** (Firebase не подключён): пароль сверяется с хэшем `CRM_PASS_HASH` в `js/config.js`. Данные хранятся только в этом браузере.
- **С Firebase**: CRM входит в аккаунт `CRM_EMAIL` с введённым паролем. Защиту данных обеспечивают Firebase Auth и правила `firestore.rules`.

## Подключение Firebase

Общий проект для магазина и CRM:

1. https://console.firebase.google.com → создать проект.
2. **Authentication → Get started → Email/Password → Enable.**
3. **Authentication → Users → Add user**: email администратора и пароль CRM.
4. Скопировать **User UID** этого пользователя.
5. **Firestore Database → Create database** (production, регион `eur3`).
6. **Firestore → Start collection** `admins` → ID документа = UID → любое поле, например `role` = `owner`.
7. **Firestore → Rules**: вставить содержимое `firestore.rules` → Publish.
8. **Project settings → Your apps → Web (`</>`)**: скопировать `firebaseConfig` в `FIREBASE` в `js/config.js` этого репозитория **и** сайта магазина.
9. В `CRM_EMAIL` указать email из шага 3.
10. **Authentication → Settings → Authorized domains**: добавить `enzorockfort-afk.github.io`.

## Перенос демо-данных

Если CRM уже велась в демо-режиме: «Данные → Скачать копию» → подключить Firebase → войти → «Загрузить копию».
